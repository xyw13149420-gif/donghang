# 懂行 · 电商人的随身助手

一个纯静态的电商经营小站：**把 GMV 拆成七个乘数，把指标口径、行业黑话、广告法红线、单品利润放进同一个页面。**

在线地址：https://xyw13149420-gif.github.io/donghang/

## 它解决什么问题

新手做电商，最容易栽在三个地方：

1. **不知道一个数是怎么来的** —— 只看 GMV 涨跌，不知道是曝光、点击、加购、下单、支付、客单哪一环出了问题；
2. **不知道一个词是什么意思** —— 运营嘴里全是 CTR、ROI、坑产、动销，听不懂就没法判断；
3. **不知道一句话会不会违规** —— 标题里写"最"、"第一"、"100%"，可能直接下架罚款。

这个站点分别对应三页：**拆解 / 认词 / 避坑**，再加两页动手的：**算账**（53 条公式可代入计算）、**试价**（这单到底赚不赚）。

## 几个设计取舍

- **只做乘法树，不做 KPI 卡片墙。** KPI 卡片只告诉你"结果是多少"，乘法树告诉你"该动哪一环"。示例店里，曝光多了 12.1%、点击率掉了 15.8%，GMV 反而跌了 1% —— 这种判断，卡片墙给不出来。
- **所有结果都是算出来的，页面里不写死数字。** 改 `data.js` 里的乘数，整站跟着变。
- **口径三问常驻。** 分母是谁、周期多长、含不含退款 —— 这三个问题不先问清楚，算出来的数都是假的。
- **纯静态、零依赖、零外部请求。** 双击 `index.html` 就能跑，也能直接托管在 GitHub Pages。CSP 默认全禁，只放行同目录资源。
- **数据留在本机。** 导入后台报表后只写 localStorage / sessionStorage，不上传任何服务器。

## 技术

原生 JavaScript（无框架、无构建、无后端），约 110KB `app.js` + 50KB `data.js`。
公式求值用递归下降解析器 + AST，不用 `eval` / `new Function`，所以能开严格的 CSP。

## 目录

```
index.html   页面骨架与侧栏导航
style.css    设计令牌与全部样式
data.js      104 个术语 / 53 条公式 / 示例店铺数据 / 违规词库
import.js    后台报表导入解析
app.js       七个视图与全部交互
```
